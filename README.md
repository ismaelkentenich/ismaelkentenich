## 🧠 About Me

I am a **Mobile Software Engineer** graduated in **Information Systems (UEMG)** with a postgraduate degree in **Full Stack Development (Estácio)**. Specialized in architecting scalable mobile solutions with **React Native, Expo, and TypeScript** for high-impact domestic and international enterprise platforms.

- **Mobile Architecture & Engineering**: Expertise in complete mobile lifecycles, Expo Router, Redux Toolkit, Zustand, Design Systems, and performance optimization.
- **DevOps & Release Management**: Proven track record handling automated CI/CD builds, OTA Updates, EAS, App Store Connect, Google Play Console, and TestFlight deployments.
- **AI/ML & Generative AI**: Certified in **GenAI** and **AI-Assisted Development**, integrating AI agents and LLM tooling into modern engineering workflows.
- **Full Stack & Cloud Systems**: Strong backend integration capabilities using Node.js, Express, NestJS, REST APIs, GraphQL, and AWS Cloud infrastructure.
- **Product Engineering Mindset**: Focused on security (Firebase App Check), observability (Analytics), agile methodologies (Kanban/Scrum), and delivering flawless UX/UI.
